# Magic Sort — веб-головоломка

Браузерная игра-сортировка цветных шаров по колбам в стиле _Magic Sort / Water
Sort_. Проект — чистый HTML / CSS / JavaScript без зависимостей и сборки. Это
делает его лёгким для встраивания (`<iframe>`), запуска внутри мобильного
WebView, и подключения к внешним системам (рейтинги, бонусы, профиль игрока)
через `postMessage`.

## Возможности

- 60 уникальных уровней (детерминированный генератор: один уровень → одно
  стабильное решение).
- Прогрессия сложности: рост числа цветов и колб, фичи открываются постепенно.
- Усложнения: скрытые шары (`?`), заблокированные колбы, лимит ходов.
- Управление tap-to-tap (клик / тап) + drag-and-drop. Touch и мышь работают
  одинаково.
- Адаптивный UI, тёмная / светлая тема, безопасные отступы для iOS notch.
- Локальный прогресс (звёзды, лучший результат, разблокированные уровни) в
  `localStorage`.
- Подсказка, отмена хода, рестарт уровня, выбор уровня, настройки.
- Хуки интеграции через `postMessage` для синхронизации с внешним
  приложением — см. ниже.

## Запуск

```bash
# Любой статический сервер. Например:
npx http-server -p 8080
# или
python3 -m http.server 8080
```

И открыть `http://localhost:8080/`.

Файлов сборки нет — всё уже готово к деплою на любой статический хостинг
(Vercel, Netlify, S3, GitHub Pages, Nginx).

## Архитектура

```
index.html        весь UI (экраны, модалки)
styles.css        тема, вёрстка, анимации
js/storage.js     localStorage (прогресс, настройки)
js/levels.js      генератор уровней + параметры сложности
js/state.js       чистая игровая логика (правила, проверка победы, хинт)
js/integration.js postMessage <-> внешняя система
js/ui.js          рендер DOM (колбы, шары, модалки)
js/input.js       ввод (pointer events: touch + mouse)
js/main.js        контроллер (связывает всё)
```

Все модули складывают свою публичную часть в `window.MS`. Поэтому встроить
игру в страницу можно одним `<iframe>` или одним блоком `<script>`-ов из
`index.html`.

## Управление

| Действие         | Способ                          |
| ---------------- | ------------------------------- |
| Выбрать колбу    | Клик / тап по колбе             |
| Перелить         | Клик по второй колбе            |
| Drag-and-drop    | Удерживай и веди в нужную колбу |
| Отменить ход     | Кнопка `↺`, клавиша `Z`         |
| Подсказка        | Кнопка `💡`, клавиша `H`        |
| Рестарт уровня   | Клавиша `R`                     |
| Назад в меню     | `Esc` или стрелка назад         |

## Интеграция (`postMessage`)

Игра шлёт в `window.parent` события вида:

```js
{ source: "magic-sort", type, payload }
```

| `type`          | `payload`                                       |
| --------------- | ----------------------------------------------- |
| `ready`         | `{ totalLevels }`                               |
| `levelStart`    | `{ id }`                                        |
| `move`          | `{ id, src, dst, moves }`                       |
| `levelComplete` | `{ id, moves, stars, bestMoves }`               |
| `levelFail`     | `{ id, moves, reason }`                         |
| `progress`      | `{ lastLevel, levels: { [n]: { stars, ... } } }`|

И принимает входящие команды от родителя:

```js
window.frames["game"].postMessage(
  { target: "magic-sort", type: "startLevel", payload: { id: 12 } },
  "*",
);
```

| `type`           | `payload`                          |
| ---------------- | ---------------------------------- |
| `startLevel`     | `{ id }`                           |
| `showMenu`       | —                                  |
| `resetProgress`  | —                                  |
| `setSettings`    | `{ sound, vibrate, dark }`         |

## Дизайн уровней

`levels.js / paramsForLevel(n)`:

| Уровни    | Цветов | Колб (включая 2 пустые) | Фичи                     |
| --------- | ------ | ----------------------- | ------------------------ |
| 1–3       | 3      | 5                       | —                        |
| 4–7       | 4      | 6                       | —                        |
| 8–12      | 5      | 7                       | hidden (на 8, 12)        |
| 13–18     | 6      | 8                       | lock (на 15)             |
| 19–25     | 7      | 9                       | hidden, lock, moveLimit  |
| 26+       | 8–10   | 10–12                   | весь набор               |

Каждый уровень детерминирован относительно номера: `seed = n * 9973 + 137`.
Уровень собирается из решённого состояния → N случайных _валидных_ ходов
вперёд → результат гарантированно решаем.

## Звёзды

- 3⭐ — ни отмен, ни подсказок
- 2⭐ — без отмен или без подсказок
- 1⭐ — уровень просто пройден
